NÄCHSTER TERMIN – ANDROID WIDGET

Dieses Projekt ist ein echtes Android-Startbildschirm-Widget.
Es liest den Kalender direkt auf dem Android-Handy über die Android-Kalenderberechtigung.

ANZEIGE
- 📅 Nächster Termin
- Titel
- Datum/Uhrzeit
- ⏳ Noch X Std. Y Minuten
- Countdown: HH:MM:SS (läuft im Widget)
- Ort

WICHTIG
Die bisherige Google-Apps-Script-Web-App wird für das Widget nicht benötigt.
Das Widget liest den auf dem Handy synchronisierten Google Kalender direkt.

EINFACHE INSTALLATION ÜBER GITHUB
1. Alle Dateien dieses Projekts in ein GitHub-Repository hochladen.
2. GitHub → Actions → "Android APK" öffnen.
3. Workflow starten oder auf einen Push nach main warten.
4. Nach erfolgreichem Build das Artifact "NaechsterTerminWidget-APK" herunterladen.
5. ZIP des Artifacts öffnen und app-debug.apk auf dem Android-Handy installieren.
6. App "Nächster Termin" einmal öffnen.
7. Kalenderzugriff erlauben.
8. Auf dem Startbildschirm lange drücken → Widgets → Nächster Termin.

ANDROID STUDIO
Alternativ das Projekt in Android Studio öffnen und direkt auf dem Handy installieren.

Hinweis: Das APK aus GitHub Actions ist eine Debug-Version und für den persönlichen Gebrauch gedacht.
